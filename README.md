# mf-cloud-import-taskの実装方法や工夫した点、動作確認方法について

## 実装方法

1. データのマッピングと判定  
   pandas を用いて input.csv を読み込み、ご指定のシンプルな8列のデータフレームを再構成  

2. 条件分岐（逆仕訳処理）  
   各行の amount 列の文字列を走査し、「-」が含まれている場合は io（収入/支出）の判定を反転させ、それに基づいて「借方/貸方」の勘定科目と税区分（10%または対象外）を動的に決定

---

## 工夫した点

1. 文字コードの自動判定  
   chardet を組み込むことで、Windows環境で文字化けを起こしやすい Shift_JIS や UTF-8 の入力ファイルをユーザー側で意識することなく自動で判別して読み込み

2. 逆仕訳処理ロジック  
   各行の amount 列の文字列を走査し、「-」が含まれている場合は io（収入/支出）の判定を反転させ、それに基づいて「借方/貸方」の勘定科目と税区分（10%または対象外）を動的に決定できるロジックを作成（提案）

3. 金額の正規化  
   正規表現 [^\d.] を用いてカンマ、円記号、マイナス符号などを排除し、最終的に正の整数（絶対値）としてマネーフォワード仕様に適合

---

## 動作確認方法

1. テスト用入力ファイルの準備  
   日付は、2026-9-1、2026-09-02、2026/9/3、2026/09/04の形式テストデータを混在し、
   通常仕訳パターンと「金額マイナス」の逆仕訳パターンも混在させたテストデータを用意

2. スクリプト実行  
   スクリプトの実行中や実行ログにエラーがないかを確認

3. 出力結果（mf_journal.csv）の目視確認
  - ファイルの形式が指定の列項目を持ち、UTF-8、BOM付き（改行コード：CR+LF）になっているか
  - 日付がすべて 2026/09/01 のようにゼロ埋めされているか
  - 金額に - や ￥ が残っておらず、正の整数になっているか
  - 収入のマイナス（amount：-） が「借方: （category_hint）/ 貸方: （payment_account）」のように支出の仕訳に反転しているか
  - 支出のマイナス（amount：-） が「借方: （payment_account）/ 貸方: （category_hint）」のように収入の仕訳に反転しているか
